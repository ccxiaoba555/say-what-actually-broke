One line of software error copy that tells the user the brutal truth — entered in make.fun's ["Say What Actually Broke"](https://make.fun/bounty/u-po-pu-say-what-actually-broke-a2c153b5) bounty. No vague apology, no error code salad: the server ran out of memory while trying to remember what it was doing, your work is safe, and the server's dignity is not. Try again in a minute.

## Run it

```sh
python3 main.py
```

It writes the single line to `/output/entry.txt`, validated first against the gate (UTF-8, 1–200 characters, one line, not only white space).
